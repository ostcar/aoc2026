# Advent of Code 2026

This year with [roc](https://www.roc-lang.org/).

To run a day, call

```
roc dayXX.roc
```

To run with optimizations:

```
roc --opt=speed dayXX.roc
```

To only run one part:

```
roc dayXX.roc 1
```

To run the tests for a day:

`roc test dayXX.roc`


To time the sotion, run:

```
roc build --opt=speed dayXX.roc
time ./dayXX
```
